# TPS65185 Power Supply Driver

A driver for the Texas Instruments TPS65185 multi-rail power supply.

The device brings its rails up when started and powers them down when stopped. `tps65185_set_vcom()` can adjust VCOM while the rails are on.

See: https://www.ti.com/lit/ds/symlink/tps65185.pdf
